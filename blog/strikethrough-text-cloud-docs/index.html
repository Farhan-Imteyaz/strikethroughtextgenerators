How to Strikethrough Text in Google Docs

The shortcut, the menu path, how to remove it, what happens in Suggesting mode, and how to do it on mobile.

The Google Docs Strikethrough Shortcut

Select the text you want to cross out, then press:

  • Windows / Chrome OS: Ctrl + Shift + X
  • Mac: Cmd + Shift + X

The selected text gets a line through it immediately. Press the same shortcut again on the same selection to remove it.

Using the Format Menu Instead

If you'd rather click than memorize a shortcut, select your text, open Format in the top menu, choose Text, then click Strikethrough. It applies the exact same formatting as the keyboard shortcut — pick whichever is faster for you.

Removing Strikethrough

Strikethrough is a toggle, not a one-way action. To remove it, select the struck-through text and either press Ctrl+Shift+X (or Cmd+Shift+X on Mac) again, or go back through Format > Text > Strikethrough — both switch it off the same way they switched it on.

Strikethrough in Suggesting Mode

If your document is set to Suggesting mode instead of Editing, deleting text doesn't remove it outright — Docs shows it with an automatic strikethrough and a colored highlight as a tracked change, alongside your name and the date. This is a different mechanism from manually applying strikethrough formatting: it's Docs marking a proposed deletion for the document owner to accept or reject, not a style you chose. Accepting the suggestion deletes the text for real; rejecting it removes the strikethrough and restores the original text.

Google Slides and Google Sheets

The same Ctrl+Shift+X (or Cmd+Shift+X on Mac) shortcut works inside text boxes in Google Slides. In Google Sheets, use Alt+Shift+5 on Windows, Cmd+Shift+X on Mac, or the same Format > Text > Strikethrough menu path.

Google Docs on Mobile (iOS & Android)

The keyboard shortcut doesn't apply on phones or tablets. Instead, select the text, tap the formatting icon (a capital A) in the toolbar above the keyboard, then tap the strikethrough icon — an S with a line through it — in the panel that opens. The formatting is identical to desktop once applied; it's just a different path to get there.

Why It Disappears When You Paste It Elsewhere

Google Docs applies strikethrough as document formatting — a style attribute attached to that text, similar to bold or italic. That formatting only exists inside the document. Paste the text into Instagram, WhatsApp, or a plain-text field and the line vanishes, because those apps don't read Google's formatting layer.

Frequently asked questions

What is the keyboard shortcut for strikethrough in Google Docs?

Select the text and press Ctrl+Shift+X on Windows or Chrome OS, or Cmd+Shift+X on Mac.

How do I strikethrough text without a keyboard shortcut?

Select the text, open Format, choose Text, then click Strikethrough.

How do I remove strikethrough text in Google Docs?

Select the text and press the same shortcut again, or use Format > Text > Strikethrough to toggle it off.

Does strikethrough show up automatically in Suggesting mode?

Yes — deleted text appears struck through and highlighted as a tracked suggestion until it's accepted or rejected.

How do I strikethrough text on the Google Docs mobile app?

Select the text, tap the formatting (A) icon, then tap the strikethrough icon in the toolbar that opens.

Does Google Slides have a strikethrough shortcut?

Yes, the same Ctrl+Shift+X (or Cmd+Shift+X on Mac) shortcut works inside text boxes.

How do I strikethrough text in Google Sheets?

Press Alt+Shift+5 on Windows or Cmd+Shift+X on Mac, or use Format > Text > Strikethrough.

Will the strikethrough survive if I paste the text elsewhere?

No — it's document formatting, stripped out by apps that don't read it. Use a Unicode strikethrough generator if you need it to travel.
