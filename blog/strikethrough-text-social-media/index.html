How to Strikethrough Text on Social Media

Instagram, X, Facebook, TikTok, and Threads have never added a strikethrough button. Here's the one workaround that works on all of them.

Why There's No Strikethrough Button

Bio fields, captions, posts, and comments on Instagram, X (formerly Twitter), and Facebook all accept plain text only — none of them have a rich-text formatting layer the way a document editor does. That means there's no bold, italic, or strikethrough button hiding in a menu; it genuinely doesn't exist as a native feature on any of the three, and the same is true for TikTok and Threads.

The Workaround: Unicode Strikethrough Text

The fix is to generate the strikethrough before you paste it in, using Unicode combining characters instead of app-level formatting. Because the line is part of the character itself rather than a style applied by the app, it displays correctly the moment you paste it — no formatting menu required.

Instagram

Works in your bio, captions, comments, and Stories text. Generate the text, copy it, and paste it directly into the field — it renders identically to how it looked in the generator.

X (Twitter)

Works in posts and replies the same way. There's no character limit penalty for using styled Unicode characters versus plain ones — they count the same.

Facebook

Works in posts, comments, and your bio/About section. Facebook Messenger accepts the same pasted text too, since it's still just Unicode underneath.

TikTok

Works in your bio and video captions the same way. TikTok has no formatting toolbar at all in its text fields, so pasting generated text is the only route to a styled look.

Threads

Works in posts and replies, following the same plain-text rendering behavior as its sibling app Instagram.

Character Limits and Strikethrough Text

Each visible letter plus its invisible combining mark still counts as one or two characters toward a platform's limit, similar to normal typed text — using strikethrough doesn't meaningfully cost you extra room. The exact count can shift by a character here or there depending on how a specific app's counter treats combining marks, but it's not a significant difference in practice.

Why It Might Look Different on Older Phones

Because these are special Unicode characters rather than plain letters, some older Android devices or lower-resource apps use fonts with incomplete support for the combining marks, which can make the line appear uneven, doubled, or offset from the text. If that happens, regenerating with the "short" line style usually displays more consistently than the long crossline on older hardware.
